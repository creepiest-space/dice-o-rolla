# `@dice-o-rolla/dice-physics`

Renderer-neutral contracts for physical dice worlds, body snapshots, throw generation, and
settling policy.

Implement these interfaces to connect Dice O Rolla to a custom physics backend. The official
Rapier implementation is available from `@dice-o-rolla/dice-physics-rapier`.

```ts
import type { PhysicsWorld } from '@dice-o-rolla/dice-physics';
```
